## How resize works

Pointer-drag `PanelResizeHandle` on the channel-list right edge and member-list left edge.
Widths clamp (channel 180–400, members 180–360) and write through
`channelListWidthAtom` / `memberListWidthAtom` in `src/state/prefs.ts`
(`atomWithStorage`, keys `stoat.web.prefs.*`). Main chat takes leftover flex space.
Server rail stays 56px.

## Collapse UX

Channel header Users button (`toggle-member-list`) overrides `showsMemberList` via
`membersCollapsedAtom`. Collapsed state shows a slim right-edge chevron
(`expand-member-list`). Same button expands again. Pref persisted.
