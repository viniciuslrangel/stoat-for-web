Client mismatch and fix

  They accepted invalid charset, length, reserved, and promotional names.
- Server FailedValidation.error was discarded by auth-error.ts, resulting in
  “Something went wrong. Try again.”
- src/lib/onboarding.ts now provides shared Stoat validation used by both
  useLogin and useRegister. It counts Unicode code points, trims the value
  sent by onboarding, and mirrors deterministic server rules.
- src/lib/auth-error.ts now prefers server error/message fields before mapped
  fallback copy. InvalidUsername and UsernameTaken mappings remain available.
